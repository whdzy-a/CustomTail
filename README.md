# CustomTail

**把玩家的尾巴当成一张网格来改**

尾巴仍然由游戏绘制，模组在它上面「焊」额外的点 / 线 / 三角形：<br>
绑定到尾巴关节、自己解算物理、按滚转分层遮挡、用编辑器的临时图集贴图。

## 这是什么

| | |
| --- | --- |
| **模组 ID** | `CustomTail`（Rain World 1.9 · BepInEx 5.4） |
| **它做什么** | 在玩家的尾巴上附加一层由 JSON 描述的 **点 · 线 · 三角形 · 贴图** 装饰，并自己解算（PBD 距离约束 + 角度约束） |
| **尾巴怎么来的** | 完全读游戏的 `TailSegment` 参数（节数、半径、连接距离），运动照抄 `PlayerGraphics` 的尾巴更新循环 |
| **数据从哪来** | `mods/CustomTail/tailmesh/*.json`，以及 **所有启用中模组** 各自的 `tailmesh/` |
| **怎么改** | 打开 `editor/tailmesh-editor.html`（单文件、离线、双击即用），或在游戏里 `暂停 → TAILS` 换绑定 |

## 30 秒上手

1. 把模组放进 `RainWorld_Data/StreamingAssets/mods/CustomTail/`，在 Remix 里启用。
2. 进游戏 → `暂停` → **`TAILS`** → 左列选猫、中列选玩家、右列 **点一行** 绑定尾巴。
3. 想自己做：`TAILS` → **`OPEN EDITOR`** 打开编辑器；做好后 `TAILS` → **`OPEN FOLDER`** 把 json 丢进 `tailmesh/`，界面 **每次打开都会自动重扫**（或按 `F9`）。

## 关于这份文档

这份 **操作总表** 把模组里 **所有能按、能拖、能改的地方** 按九个系列列全，逐项对照代码核对过（编辑器部分覆盖了 `tailmesh-editor.html` 全部 7970 行的 `id` / `data-tool` / `data-act` / 事件监听）。

- 路径约定：`<mod>` = `RainWorld_Data/StreamingAssets/mods/CustomTail`
- 「操作点」写界面上 **真实出现的文字**；括号里补 `id` / 信号名 / 函数名，方便对着代码找
- 标了 **可手改** 的，都是「改完不用重新编译，重开界面或按 F9 就生效」

## ⚡ 速查：我想干什么 → 去哪

| 我想… | 操作点 |
| --- | --- |
| 给某只猫换尾巴 | 暂停 → `TAILS` → 左列选猫、中列选玩家 → 右列 **点一行** |
| 取消某个绑定 | `TAILS` → `CLEAR` |
| 看新做好的 json | 打开 `TAILS` 就会自动重扫（或按 `F9`） |
| 做 / 改装饰网格 | `TAILS` → `OPEN EDITOR`，或直接开 `editor/tailmesh-editor.html` |
| 往模组里丢文件 | `TAILS` → `OPEN FOLDER` |
| 让别人的模组也用上 | 那个模组的 `tailmesh/` + `tailbindings.json`（见 [系列 6](#s6)） |
| 贴图变成绿方块了 | 元素名打错 / 图集没装 / 那个模组没启用（见 [系列 1](#s1) 与 [系列 9](#s9)） |
| 滚转左右反了 | 配置 `Roll invert direction` 关掉 |
| 尾巴完全不滚 | 配置 `Roll max angle` 设 0 |

## 1 · 游戏内自动行为（不用操作）

这些没有按钮，进游戏就在跑；列出来是因为出问题时要知道去哪儿看。

| 行为 | 触发时机 | 说明 |
| --- | --- | --- |
| 尾巴网格渲染 | 每帧，有 `PlayerGraphics` 就挂 | 装饰点由尾巴解算（`MeshInstance`）驱动，一个 doc 一帧只解算一次 |
| 滚转 roll | 走路 / 趴 / 贴墙 / 悬空 / 杆上 | 上限由配置「Roll max angle」，方向由「Roll invert direction」 |
| 绕轴分层（`wrap`） | 每帧 | `sin(滚转 + 层角)` 决定这一层在尾巴前面还是后面 |
| 不旋转 sprite（`noRoll`） | 每帧 | 不吃滚转也不吃层角，位置也不随滚转偏移；永远画在最上层（Foreground） |
| 图集自动注册 | 启动、按 F9、打开 TAILS 界面 | 扫所有启用模组 `atlases/**/customtail-autoload.json`，把同文件夹的 `*.txt`+`*.png` 注册成图集 |
| tailmesh 扫描 | 启动、按 F9、打开 TAILS 界面 | 扫自己 + **所有启用中模组**的 `tailmesh/**/*.json` |
| 绑定表加载 | 启动、按 F9、打开 TAILS 界面 | 自己的 `tailbindings.json` + 各模组自带的（别人的只是默认值） |
| 缺贴图 → 绿色方块 | 创建渲染层时 | 元素名在任意图集里找不到 → 亮绿 32×32 方块；日志每张贴图只报一次 |
| 调试用品红三角 | 配置「Debug marker」开启时 | 尾巴中段一个品红三角，用来确认钩子→容器→顶点这条管线通没通 |
| 滚转统计日志 | 配置「Roll debug」开启时 | 每秒一行：roll 范围、分支来源、投影额外位移 |

## 4 · TAILS 尾部分配界面

打开方式：暂停 → `TAILS`。每次打开都会**重新扫一遍磁盘**（图集 + 所有 `tailmesh`），所以新丢进去的 json 直接可见。

### 4.1 左列 · SLUGCAT（选猫）

| 操作点 | 位置/长相 | 作用 |
| --- | --- | --- |
| 猫列表行（`CT_SLUG_0..8`） | 左列 9 行 | 点一行 = 选中这只猫；行首 `> ` 表示当前选中 |
| `<`（`CT_PGSLUG_PREV`） | 左列底部 | 上一页 |
| `>`（`CT_PGSLUG_NEXT`） | 左列底部 | 下一页 |
| 页标 | 两个箭头中间 | `当前页 / 总页数` |

> 第一项固定是 `ALL SLUGCATS`（= 所有猫），后面是 `SlugcatStats.Name` 的全部 ID（SlugBase 注册的也在里面）；有名字的显示 `名字 [ID]`。

### 4.2 中列 · PLAYER（选分屏玩家）

| 操作点 | 位置/长相 | 作用 |
| --- | --- | --- |
| `ALL PLAYERS`（`CT_PLR_0`） | 中列第 1 行 | 规则对所有玩家生效 |
| `PLAYER 1..4`（`CT_PLR_1..4`） | 中列第 2–5 行 | 只对那个 `playerNumber` 生效 |

### 4.3 右列 · TAIL（选尾巴 + 绑定）

| 操作点 | 位置/长相 | 作用 |
| --- | --- | --- |
| 尾巴列表行（`CT_TAIL_0..8`） | 右列 9 行，每行是 json 的键名 | **点一行 = 把这份网格绑给当前「猫 + 玩家」**，并立即存盘；行首 `> ` 表示当前真正生效的那份 |
| `<`（`CT_PGTAIL_PREV`） | 右列底部 | 上一页 |
| `>`（`CT_PGTAIL_NEXT`） | 右列底部 | 下一页 |
| 页标 | 两个箭头中间 | `当前页 / 总页数` |

> 列头写着 `TAIL (click to bind)`。没被任何规则点名的网格会自动套给所有玩家（别人的模组除外，见「系列 6」）。

### 4.4 概览行

| 操作点 | 长相 | 作用 |
| --- | --- | --- |
| `TARGET … -> …`（`_summary`） | 列表下方中间 | 一行看清：`猫 / 玩家 -> 生效的尾巴`，没绑就是 `nothing bound` |

### 4.5 预览框（右侧）

| 操作点 | 位置/长相 | 作用 |
| --- | --- | --- |
| `PREVIEW` 画布（280×320） | 右侧上部 | 实时预览：蛞蝓猫 + 4 节尾巴物理 + 三角形装饰 + 自由贴图，前后遮挡按当前滚转算 |
| 鼠标拖动蛞蝓猫 | 在画布内按住拖 | 整体平移身体和臀部，尾巴被连接约束拉着拉伸（不改任何数据） |
| `ROLL` 滑条（`CT_Roll`） | 画布下方 | 手动滚转 −75°…+75°；拖动会自动把 AUTO 关掉 |
| `ROLL ±N°` 标签 | 滑条下方 | 当前角度；AUTO 开着时末尾带 `(AUTO)` |
| `AUTO: OFF` / `AUTO: ON`（`CT_AUTO`） | 滑条右侧 | 开关自动左右摆（sin 扫，周期约 2.5 秒，±75°） |

### 4.6 底部按钮（一排 5 个）

| 操作点 | 位置 | 作用 |
| --- | --- | --- |
| `RELOAD JSON`（`CT_RELOAD`） | 左下 | 立刻重扫磁盘 + 重建预览（等同 F9） |
| `CLEAR`（`CT_CLEAR`） | 左二 | 删掉当前「猫 + 玩家」的绑定规则并存盘 |
| `OPEN FOLDER`（`CT_OPEN_MOD`） | 中间 | 用资源管理器打开 `<mod>`（`tailmesh/`、`atlases/`、`tailbindings.json` 都在这儿） |
| `OPEN EDITOR`（`CT_OPEN_EDITOR`） | 右二 | 用默认浏览器打开 `<mod>/editor/tailmesh-editor.html`；文件不在就打开 `editor/` 文件夹 |
| `CLOSE`（`CT_CLOSE`） | 右下 | 关闭界面（也是返回键的目标） |

### 4.7 关闭界面

| 操作点 | 说明 |
| --- | --- |
| `CLOSE` | 鼠标点 |
| 暂停键（Esc / 手柄 start） | 打开后前 8 帧不认，防止"按一下就自己关了" |
| 返回 / `backObject` | `CLOSE` 按钮已注册为返回目标 |

## 5 · BepInEx 配置（F1 → Configuration Manager，或手改 `BepInEx/config/CustomTail.cfg`）

| 配置项 | 类型 | 默认 | 作用 |
| --- | --- | --- | --- |
| `Reload tail mesh key` | 快捷键 | `F9` | 热重载 JSON 的键 |
| `Roll max angle` | 0–180 度 | `75` | 滚转幅度上限；0 = 完全不滚（只用 JSON 里的 `physics.tailRoll`） |
| `Roll invert direction` | 开关 | 开 | 左右滚转方向；发现左右反了就关掉 |
| `Roll debug` | 开关 | 开 | 每秒往日志打滚转统计（角度范围、分支来源、投影额外位移） |
| `Debug marker` | 开关 | 开 | 尾巴中段画品红三角，确认管线通 |
| `Auto register atlases` | 开关 | 开 | 自动注册各模组 `atlases/` 里带标识文件的图集 |

## 6 · 文件与目录（谁读哪里）

| 路径（相对 `<mod>` 或游戏根） | 谁读 | 可手改 | 说明 |
| --- | --- | --- | --- |
| `tailmesh/**/*.json` | 模组启动 / F9 / 打开界面 | ✅ 可手改 | 每份文件 = 一条尾巴网格；**键名 = 相对路径去掉 `.json`**（子目录用 `/`） |
| `tailbindings.json` | 同上 | ✅ 可手改 | `{ rules: [ { tail, slugcat, player } ] }`；`slugcat: "*"` = 所有猫，`player: -1` = 所有玩家 |
| `atlases/**/customtail-autoload.json` | 启动 / F9 / 打开界面 | ✅ 可手改 | 图集自动注册的**标识文件**；`{"autoRegister": false}` 可关掉这一份 |
| `atlases/**/*.txt` + 同名 `*.png` | 同标识文件所在文件夹 | ✅ 可手改 | 有标识文件才注册；图集名 = 相对模组根的路径（如 `atlases/rim1`） |
| `editor/tailmesh-editor.html` | 游戏内 `OPEN EDITOR` 打开 | ✅ | 编辑器本体（单文件、离线） |
| `editor/atlas-cache/` | 编辑器启动时 | 可删 | 图集缓存（`atlas_dump.py` 生成），删了重跑即可 |
| `thumbnail.png` | 游戏模组列表 | ✅ | 封面（1600×900，16:9） |
| `modinfo.json` | 游戏 | ✅ | 模组声明（id 必须是 `CustomTail`） |
| 其它启用模组的 `tailmesh/` | 启动 / F9 / 打开界面 | — | 只读；键名重名时后加载的改叫 `键名@模组名`；**默认不生效**，要在 `tailbindings.json` 里点名 |
| 其它启用模组的 `tailbindings.json` | 同上 | — | 只当**默认值**：自己的规则同分时赢，菜单保存也不会把它们写回自己的文件 |
| `BepInEx/LogOutput.log` | 游戏 | — | 所有日志（`[CustomTail] …`） |

<details>
<summary><b>7.15 调试入口与已知边角</b></summary>

| 操作点 | 位置/长相 | 作用 |
| --- | --- | --- |
| `window.__test` | 不可见，控制台可达 | 一次性导出约 200 个内部符号：`S`、`ex/im/snap`、`step/solve/settle`、`pickNode/pickLink/pickTri/pickAngle/pickTailVert`、`addTri/delTri/applyTex/splitSelected`、`addSprite/drawSprite/spriteBasis`、`LIB/libLoadPack/useSprite`、`PROJ/saveProject/newProject`、`TEMP/tempCommit/tempAutoLayout/tempTxt`、`MOD/modOpen/modGenerate/modZipBytes/modCoverCanvas`、`props/phys/render` 等。**唯一的真正调试入口** |
| `window.__test.MOB` | 不可见 | 额外挂移动端状态对象与 `mobOpsOpen` / `mobBarSync`，便于在控制台断言抽屉状态 |
| `window.ATLAS_PACK` | 由 `atlas-cache/atlas-pack.js` 提供 | 启动时自动装载图集库并 toast「图集库已载入 N 个图集 / M 个 sprite」；没有这个文件也能用，只是图集页签为空 |
| `window.__atlasPackError` | 由 `<script onerror>` 写入 | **死旗标**：只写不读，没有任何地方检查它 |
| 隐藏文件输入 ×5 | `display:none` | `#fi`（打开 JSON）、`#libDir`（选 mods 目录）、`#libFiles`（多选 png/txt/json）、`#tempPng`（插入 PNG）、`#tempAtlasFiles`（打开图集）；只能由面板按钮触发 |
| `LIB.limit = 240` | 图集页签 | 隐藏上限：sprite 网格最多渲染 240 个，超出靠搜索缩小 |
| IndexedDB `customtail-editor` | 无 UI | 只存「上次打开的 File 句柄」，不存文档内容 |
| `COARSE` / `HIT` | 无 UI | 粗指针设备上所有拾取半径 ×1.8 |
| `localStorage` / URL 参数 | — | **完全没有**：没有 `localStorage`、`sessionStorage`、`location.search`、`?debug`、`#hash` 开关 |

**只出现在特定条件下的控件**

- **左栏整栏**只在有选中对象时滑出，且按类型整块替换：三角形 / 多点批量 / 单点 / 线 / 角度 / sprite，互斥。
- sprite 的「层角」组只在**位置点是基准点**时出现。
- 映射范围的 `X/Y/W/H` 与「按当前形状重设范围」只在关掉「自动贴合」后出现。
- 绑定参数组按 `bind.kind` 四选一；基准点与身体锚点被选中时只有只读坐标，没有任何编辑控件。
- 三角形组的 `L` / `×` / 改名框只在有组时存在；「未成组的三角形」只在有 `tex===null` 的面时才有行。
- 图集页「模组」下拉只在来源 >1 时渲染；来源 chips 数量为 0 的不渲染；临时图集的「清空」只在已载入时出现。
- 模组弹窗的「临时图集」勾选框在没有临时图集时置灰；「生成 ZIP」会做硬校验。
- `#bresume` 只在 IndexedDB 有上次句柄时出现；`#mmore` / `#mobar` / `#mveil` 只在移动断点显示；`#prShow` 只在右栏收起后显示；`#pickbar` 只在选点模式显示。

**写好了但没接线 / 已知不一致（照实列出）**

- `mergeInto(g)` 与 `selectGroup(g)` 有完整实现，但没有任何 UI 调用点（只挂在 `__test` 上）；三角形组行里的 `L` 按钮是就地写了一遍同样的合并逻辑。
- 顶栏项目名 chip 看起来像按钮，点了只弹一条 toast，不打开任何对话框。
- `sprite.order` 字段导入导出都带着，但**没有 UI 改它，绘制也不看它**（排序靠左栏「上移一层/下移一层」）。
- 删除工具的兜底提示提到「面」，但 `X` 工具分支只处理点/角度/线，**删面只能靠 Del 键或左栏「删除面」**。
- 模组弹窗打开时焦点在「模组名」输入框里，而 `if(typing)return` 在 Esc 分支之前 —— **刚打开时按 Esc 关不掉**，要先点一下别处。
- 「绑定」工具点同一个点两次、连线工具连点同一个点两次，都是静默 return，没有提示。
- **没有网格吸附**（背景点阵只是装饰）、**没有对齐/分布功能**、**没有自动保存**、**没有独立日志面板**（反馈都是 2.4s toast）。
