鼠标：左键点选 / 拖动；空白处拖动 = 拉框；中键拖动 = 平移； 右键 = 操作菜单；滚轮 = 缩放（以指针为中心）。
对象：右侧「对象」栏按 点 / 线 / 三角形组 / 未成组的面 / 自由贴图 分类列出所有对象， 点一行即选中（Shift+点击 加选）；选中后左侧「属性」栏自动滑出，取消选择就收起。 右栏右上角的 › 可以把它收到右边，点右边缘的 ‹ 把手拉回来。
Shift+点击 加选 / 取消；Alt+点击 在重叠的点之间轮换。
工具：V 选择 · F 施力 · P 加点 · L 连线 · T 三角面 · A 角度 · S 自由贴图 · B 绑定 · X 删除。
层：拖动左下罗盘换编辑角（15° 吸附），[/] 也能转； 顶部层条 左边圆点 = 显隐这一层，右边角度 = 跳过去编辑。
文件：Ctrl+S 保存 · Ctrl+Shift+S 另存为 · Ctrl+O 打开 · Ctrl+N 新建 · Ctrl+Z / Ctrl+Y 撤回重做 · Ctrl+C/V 复制粘贴 · Ctrl+A 全选当前层 · Del 删除 · Esc 取消。
贴图：一个对象一张图；「走图集贴图」= 游戏里的 SetAtlasedImage；染色是乘法（白 = 不染）。
自由贴图：位置 / 方向只能点选已有的点；列表里的上下顺序 = 遮挡顺序（越靠后越在上面）。
选择/拖动 改形状（同步静止长度）；施力拖动 只拖点、不动线长，松手回弹。
基准点（橙色方块）：尾巴表面 9 个共享骨架点，不能删除，任何层都能连到它。
骨架锚点（躯干 / 臀部 / 尾根）：选择工具拖动 = 三点按固定距离整组平移，尾巴顶点留在原地被约束拉； 施力工具拖 body 点 = 只动那一个、另一个钉住，距离锁死（两个 body 的相对方向会转）。
