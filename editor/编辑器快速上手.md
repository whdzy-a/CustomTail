# CustomTail 尾部编辑器 · 快速上手教程

> 目标：10 分钟内做出第一条"会跟随玩家、能摆动"的自定义尾巴。
> 编辑器是一个**单文件离线网页** `editor/tailmesh-editor.html`，双击用浏览器打开即可，不需要安装任何东西。

---

## 0. 先认识画布里的三种点

打开编辑器后，画面中央会出现几类预设的点，这是理解的钥匙：

| 形状 | 名称 | 含义 | 能删/能拖吗 |
|------|------|------|-------------|
| 🟠 橙色方块 | **尾巴基准点** | 尾巴表面 9 个共享骨架点（身体自带） | 不能删；只能**拖动**改变形状 |
| 🔵 青色圆圈 | **骨架锚点**（躯干 / 臀部 / 尾根） | 玩家身体在游戏里的位置 | 不能删；拖动会让整组一起平移 |
| ⚪ 白点 | **你自己加的点** | 自由点，用来搭线、铺面、贴图 | 随意增删拖 |

> 记不住也没关系：编辑器右上角有个 **`?` 帮助按钮**，里面有完整操作说明，随时可点开看。

## 1. 界面一览（30 秒）

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：  ↶↷  |  ⏸暂停 ⏮重置 | 新建 打开 保存 另存为        │
├──────────────────────────────────────────────────────────┤
│ 工具条：V选择 F施力 | P点 L线 T面 S贴图 A角 | B绑定 X删    │
│         [重设初始位置] [删离散点]  当前贴图   ?             │
├──────────┬───────────────────────────────┬───────────────┤
│ 属性(左) │         画布 (滚轮缩放/中键平移) │ 对象/物理/尾巴 │
│          │  左下：编辑角度罗盘 🧭          │ /图集 (右)    │
├──────────┴───────────────────────────────┴───────────────┤
│ 状态栏：当前工具 · 提示                                  │
└──────────────────────────────────────────────────────────┘
```

- **工具条**：选工具后，在画布上操作。快捷键写在每个工具名字后面（V / F / P / L / T / S / A / B / X）。
- **右侧栏**有 4 个页签：`对象`（所有点/线/面/贴图列表）、`物理`（尾巴和点的物理参数）、`尾巴`（整体滚转）、`图集`（贴图来源）。
- **左下角罗盘 🧭**：用来切换"绕轴角分层"，后面第 6 节讲。

## 2. 五分钟搭出一条尾巴（动手）

### 第 1 步：加点（P）
按 `P`，在画布上**点几下**，放出一排白点。这是你尾巴的骨架顶点。
> 提示：点空白处 = 新建点；在已有点上点 = 选中它。

### 第 2 步：连线（L）
按 `L`，依次点击两个相邻的点，它们就连成一条**边（线）**。
> 把整排点连成一条链，就是尾巴的骨架。线的"松紧"由右侧属性面板里的 `stiffness`（刚度）控制。

### 第 3 步：铺三角形面（T）
按 `T`，依次点 **3 个点** → 围成一张三角形面；继续点下一组 3 点可以连续铺面。
> 三角形会被自动**分组**：每一组共用一张贴图、连续变形。这就是游戏里看到的尾巴"皮"。

### 第 4 步：贴上贴图
1. 在右侧栏切到 **`图集`** 页签，挑一张图（若没有图集，可先把 PNG 拖进"临时图集"）。
2. 回到画布，按 `S`（自由贴图）或选中三角形组后在属性面板的"贴图"里选图。
3. 贴图按 **UV 连续变形**贴到三角形上——不是每张面各铺一遍。

### 第 5 步：让尾巴动起来
顶部点 **⏸暂停 / 继续**（或按 `空格`）开始模拟。
- 用 **V（选择/拖动）** 拖点：会**改变静止形状**（同时记住线的长度）。
- 用 **F（施力拖动）**：只把点"推"一下，松手就回弹，不改形状。
- 顶部 **⏮重置**：自由点瞬间回到静止位置。

✅ 到这里，你已经拥有一条能在编辑器里被拉扯、回弹的尾巴了。

---

## 3. 绑定到玩家身体（关键）

光有线是不够的——尾巴要**跟着蛞蝓猫的身体动**。做法是把点**绑定（B）**到身体骨架：

1. 按 `B`（绑定工具）。
2. 点一个你的白点 → 再点一个**橙色基准点**或**青色骨架锚点**，就把这个白点"挂"到身体上了。

绑定类型（在属性面板里选）：
- `free`：自由点，只受线约束。
- `body` / `tail` / `tvert`：分别挂到身体块、尾巴段、尾巴基准骨架点。
  - 挂到 `tvert`（橙色基准点）最稳：这是身体自带的共享骨架，任何层都能连。

> 经验法则：**至少把尾巴根部几个点绑到身体**，尾巴才会随玩家移动和摆动；末端让它自由，才有"飘"的感觉。

## 4. 工具速查表

| 工具 | 快捷键 | 干什么 |
|------|--------|--------|
| 选择 / 拖动 | `V` | 改形状（同步静止长度） |
| 施力拖动 | `F` | 只推点、不动线长，松手回弹 |
| 加点 | `P` | 放一个新点 |
| 连线 | `L` | 两点之间连一条边 |
| 三角形组 | `T` | 三点围成面，连续铺面 |
| 自由贴图 | `S` | 不贴三角形的独立图片（位置/方向只能选已有点） |
| 角度 | `A` | 点 3 个点设一个角度约束（固定两条边的夹角） |
| 绑定 | `B` | 把点挂到身体骨架 |
| 删除 | `X` | 删选中的点/线/面/贴图 |

**通用操作**
- 左键：点选 / 拖动；空白处拖动 = 拉框多选
- 中键拖动：平移画布；滚轮：以指针为中心缩放
- 右键：操作菜单；`Shift`+点击 = 加选/取消；`Alt`+点击 = 重叠点轮换
- `Ctrl+Z` / `Ctrl+Y`：撤回 / 重做；`Ctrl+A`：全选当前层；`Del`：删除；`Esc`：取消

---

## 5. 两个实用按钮（工具条右侧）

- **重设初始位置**：把"当前所有点的位置"写成新的**静止形状**。做造型调满意后点它，尾巴下次回弹就回到这个姿势。
- **删离散点**：清掉那些"没有任何线 / 面 / 贴图 / 绑定引用"的孤立点，整理画布用。

---

## 6. 分层：绕轴角（进阶）

想给尾巴做"侧面也有装饰、转到不同角度看到不同花纹"？用**左下角罗盘 🧭**：

- 拖动罗盘转到某个角度（15° 吸附），或按 `[` / `]` 微调。
- 此时你画的所有点/面/贴图都只属于**这一层角度**。
- 顶部层条上：左边圆点 = 显隐该层，右边角度 = 跳过去编辑。
- 游戏里尾巴滚转时，会自动按当前角度显示对应那一层的装饰。

> 简单理解：每一层 = 尾巴转到某个朝向时"该露出来的那一面"。

---

## 7. 物理参数（右侧 `物理` / `尾巴` 页签）

- **尾巴页签**：`tailRoll` 整体滚转（-1 向左半圈 → 0 不滚 → +1 向右半圈）。这就是游戏里尾巴的默认姿态。
- **物理页签**：
  - `gravity` / `tailGravity`：重力（每步速度增量）。
  - `iterations` / `tailIterations`：约束迭代次数，越大越"硬"。
  - `damping`：阻尼，越大越慢、越稳。
  - `air`：空气阻力。
- 这些参数和游戏内 `PlayerGraphics` 的尾巴物理**一一对应**，所以编辑器里看到的摆动≈游戏里看到的。

---

## 8. 保存与载入

- **保存**（`Ctrl+S`）：存成 `.json`。第一次保存会问你存哪；之后直接覆盖。
- **另存为**（`Ctrl+Shift+S`）、**打开**（`Ctrl+O`）、**新建**（`Ctrl+N`）。
- 顶栏的 **继续上次项目**：一键重开上一次编辑的文件。
- 贴图的像素会**内嵌进 JSON**，所以换电脑打开也不会"贴图全丢"。

> 保存后的 JSON 会被游戏模组 `CustomTail` 读取，在对应的蛞蝓猫/玩家身上渲染出你设计的尾巴。

---

## 9. 常见卡点

- **尾巴不动？** 顶部点一下 ⏸ 继续模拟（空格），并确认至少根部点已绑定到身体。
- **看起来像纯色？** 没载入图集/临时图集，或三角形没指定贴图。去 `图集` 页签选图。
- **拉扯后回不到原样？** 先点 ⏮重置；想让新姿势成为默认，用 **重设初始位置**。
- **点太多太乱？** 用 **删离散点** 清理孤立点。

完成以上步骤，你就掌握了编辑器的核心闭环：**加点 → 连线/铺面 → 绑身体 → 贴图 → 调物理 → 保存**。剩下的细节都在右上角 `?` 帮助里。
